# 社畜反击战

纯 HTML + CSS + JavaScript Canvas 竖屏全屏交付闯关小游戏。页面按手机小游戏全屏体验设计，双击 `index.html` 或在手机浏览器打开即可游玩。

## 文件结构

```text
社畜反击战/
├── index.html
├── README.md
├── style.css
├── tests/combat.test.cjs
└── js/
    ├── audio.js     # 开场与战斗音效、静音设置
    ├── renderer.js  # 矢量人物、场景、特效和 HUD
    ├── data.js
    ├── input.js
    ├── entities.js
    ├── game.js
    └── main.js
```

## 触屏操作

底部操作区左右均分：左侧负责移动，右侧负责攻击和系统操作。

- `← / →`：移动
- `跳`：跳跃
- `蹲`：下蹲
- `普攻`：键盘连击
- `反弹`：需求反弹
- `突刺`：上线单突刺
- `远程`：扔订书机
- `大招`：已读不回
- `特权`：模拟观看广告后领取一次续航/专注/质量补救
- `开始`：开始 / 暂停 / 通关后重开

键盘仍可作为桌面调试备选：方向键移动，`Space` 跳跃，`S` 下蹲，`1/2/3 + J` 出招，`K` 远程，`L` 大招，`V` 领取特权，`Enter` 开始或暂停。

## 招式

触屏按钮会直接释放对应招式：

- `普攻 / 键盘连击`：稳定近战三连击，适合清小怪和贴身打 Boss。
- `反弹 / 需求反弹`：短暂架起蓝色反弹盾，把 Boss 的飞行道具反打回去，对 PPT 光波、大饼、裁员风暴这类招式特别有用。
- `突刺 / 上线单突刺`：向前爆发突进并打出高伤害，适合 Boss 放完硬直后的反击。

每种招式都有独立特效和浮字反馈：键盘连击是黄色/粉色连击斩，需求反弹是蓝色盾面，上线单突刺会打出交付物冲刺轨迹。

攻击、反弹、突刺和受击不会暂停游戏。普攻具有蓄力、命中和收招阶段；支持长按连续攻击和 200ms 的连招输入缓存。轻量镜头反馈、弧形斩击和粒子拖尾保留打击感，命中提示不会阻塞操作。大招“已读不回”的 3 秒冻结仍是原有技能效果。

角色使用矢量分层绘制，包含面部表情、眨眼、呼吸、跑步关节、挥击、收招和受击后仰。场景使用多层城市视差、窗框、地面透视、桌椅侧面和接触阴影。大招按钮和 HUD 同步显示充能状态，通关后进入完整结算场景。

## 玩法目标

你是一名普通打工人，本局目标不是单纯发泄，而是把一个延期事项从需求确认一路推进到上线交付。

每一层都有“事项推进段”和“Boss 验收段”。玩家需要收集关键资料、处理阻碍、保持体力和心态，事项进度达到本层门槛后才能进入验收战：

1. 1F 开放工位区：组长·卷王
2. 2F 会议室：主管·会霸
3. 3F 经理办公室：经理·甩锅侠
4. 4F 总监楼层：总监·画饼大师
5. 5F 顶楼 CEO 室：CEO·资本之神

玩家有体力条、心态条、怒气条、事项进度和交付质量。体力归零会倒下，心态被打空会进入“破防”状态并短暂无法操作，受击会轻微降低交付质量。主角头顶会常驻显示当前体力/体力上限，方便战斗中直接判断还能扛几下。拾取咖啡能回血和加速，拾取订书机补充远程弹药，拾取资料会推进事项进度，每层隐藏一个带薪拉屎点，碰到后会回满心态。

原地不动 3 秒会进入摸鱼状态并缓慢恢复心态。事项进度、交付质量、资料收集、特权使用、摸鱼次数、被打倒次数、通关时间会影响最终结算评分和称号。

## 广告特权方案

当前版本预留了激励广告入口：`特权` 按钮或键盘 `V` 会模拟一次“观看广告成功后领取奖励”。

特权不会直接通关，而是按当前局势发放有限帮助：低体力/低心态时给状态续航，交付质量偏低时给质量补救，状态良好时给 8 秒专注加成、怒气和弹药。每局默认 3 次，结算会记录特权使用次数。

后续接广告 SDK 时，把广告播放完成回调接到 `Game.grantAdPrivilege()` 即可；广告开始、失败、关闭未完成等状态可在 `Game.requestAdPrivilege()` 外层扩展。

## 调整建议

游戏参数集中在 `js/data.js`。可以在那里调整 Boss 血量、场景颜色、敌人数量、补给位置和障碍位置。

## 2026-11 UI 与动作更新

- 女生主角采用高马尾、薄荷色外套与奶油色衬衫，包含随动作摆动的发型和连续攻击姿态。
- 深蓝与暖金漫画风主菜单、桌面说明栏、楼层路线和立体触屏按钮；移动端保持画面比例，避免人物被拉长。
- Canvas 根据实际显示尺寸和设备像素比调整清晰度；不再使用像素化 CSS 缩放。
- 删除每次出招强制停止整个战斗的 hit-stop；普通攻击使用连续动作与延迟命中，突刺和 Boss 冲刺改为连续位移。
- 每帧渲染，模拟步长不超过 1/120 秒，支持不同屏幕刷新率；镜头平滑跟随，HUD 保持稳定。
- 普通敌人与 Boss 被命中后进入受击硬直，打断追击、攻击和冲刺，并连续后退。角色之间加入身体阻挡，优先保留主角的占位，接触伤害不会把主角挤走；墙边不能继续把对手推到场景外。跳跃越过敌人和击败后通行仍然有效。
- 切换标签页自动暂停，失焦清除输入；键盘与触屏均可开始、暂停、继续。
- 游戏资源均保存在本地，不依赖图片 CDN、外部字体或额外运行库。

### 游戏音效

点击开始或按 Enter 后播放短促上扬的开场旋律。普攻挥击与命中分开触发，三段连击、反弹、突刺、远程和大招各有音色；被击中和成功格挡也有反馈。冷却中、无弹药等未成功出招的输入不会播放攻击音。

前进和后退时会淡入一段轻快的持续节奏，以四秒无缝循环播放；停止、撞墙或被角色挡住时在 0.2 秒内淡出。移动跳跃保持连贯，下蹲更轻，加速时节奏略微加快。循环复用同一音源，快速停走不会从头重播或叠加；暂停、静音、切到后台和音频中断会立即结束循环。

前进和后退还会随实际步幅播放轻量脚步声，加速时步频变快，下蹲时更轻；原地、撞墙、被阻挡及空中不会连续响脚步。起跳和落地各触发一次反馈。咖啡、资料、弹药和首次使用休息点各有不同的获得提示，已收集的物品不会重复播放。

开始页面和战斗操作栏均可切换“音效开 / 已静音”，设置会保存在当前浏览器。暂停和切到后台会停止当前声音，恢复后不补播。音效通过 Web Audio 在本地合成，无需加载音频文件；不支持音频或音频启动受限时，游戏仍可正常操作。

### 手机与微信内置浏览器声音

开始和暂停按钮在抬手时触发，音频在 `pointerup` / `touchend` 的真实操作内解锁，兼容触控按钮取消默认 click 的情况。首次启动会在操作中播放一个静音采样以初始化移动端音频；支持 Audio Session API 的浏览器会使用媒体播放通道。切到后台或音频被打断时，旧音效会被清除，下次触摸可恢复；关闭的 AudioContext 可在用户操作时重新创建。

音效尚未启动成功时显示“点此启声”，点击会重试并播放短提示音；成功后显示“音效开”。刷新后保留已静音设置。若微信中仍然无声，请点击启声、调高手机媒体音量，并检查声音是否输出到蓝牙设备；可用系统浏览器打开相同地址对照。自动测试覆盖触屏启声限制和中断恢复，实际微信音频仍需在具体手机上确认。

### 敌人攻击与反击

主角进入警戒范围时，普通敌人会转身接近，在出招距离内停下并蓄力。HR、实习生和汇报怪使用不同节奏的近身攻击，头顶显示攻击提示和蓄力条，挥击时有红色轨迹与独立音效。伤害只在挥击帧检查，退开、跳起或绕到背后可避开，需求反弹可格挡。

命中会打断敌人动作并击退；同一段硬直不会被连续命中无限重置。仍存活的敌人在硬直结束后优先尝试反击，五层 Boss 也会进行近身重击或恢复原有技能。出招时固定朝向和位置，不会穿过或推动主角；暂停、冻结、死亡都会阻止攻击继续生效。

### 顶层极限验收

第 5 层 CEO 改为三阶段最终战，血量 560。护盾期间仅承受 8% 伤害，连续施放左右交替的全高危险区；必须看准带箭头的青色安全区急转，单靠一直向前或跳跃不能躲过。三阶段分别连续切换 2、3、4 次，预警时间从 1.28 秒缩短至 1.08 秒，安全区逐渐收窄。每轮第一招额外留出 0.45 秒回位时间，不随机把安全区放到无法到达的位置。

急转连招后紧接地面横扫：留意倒计时，在落地前跳起，也可用反弹格挡。横扫结束后 Boss 破盾 2.8–3.2 秒，承受 1.5 倍伤害，适合冲上去连击或使用大招。盾内受击不会取消预警，Boss 施法时不向前挤占角色。场地锁定在一屏内，血条下常驻招式、连续次数、倒计时，场内显示危险区、安全区与护盾。

最终战失败后满体力、满心态重试当前 Boss；前四层原有流程保持不变。自动化使用真实移动、跳跃和普通攻击模拟 30/60/120 Hz 通关，并验证第三阶段预警留有 180ms 的变向反应时间。手机手感仍以真机试玩为准。

### 本地运行与验证

直接双击 `index.html`，或在项目目录执行：

```sh
python3 -m http.server 8765
```

用浏览器打开 `http://localhost:8765/`。运行战斗回归检查（需要 Node.js）：

```sh
node --test tests/*.test.cjs
```
